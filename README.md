# Lenguajes de Marcas y Sistemas de Gestión de Información — 1.º DAW

Prácticas del módulo de **Lenguajes de Marcas** de 1.º de DAW (curso 2025-2026): HTML5, CSS3 (incluido diseño responsive con Flexbox y Grid), JavaScript y el DOM, XML con DTD y XSD, transformaciones XSLT y JSON.

## Tecnologías

HTML5 · CSS3 · JavaScript · XML · DTD · XSD · XSLT · XPath · JSON

## Cómo verlo

Son páginas estáticas: basta con abrir el `.html` en el navegador. Para los XML enlazados a una hoja XSLT conviene usar un servidor local (por ejemplo la extensión *Live Server* de VS Code), porque algunos navegadores bloquean XSLT con `file://`.

## Notas

- **Reproductor de música (`t3-javascript/mp3`)**: no se incluyen los ficheros `.mp3` por licencia. Para probarlo, añade tus canciones en `t3-javascript/mp3/music/` con los nombres que aparecen en `app.js`.
- **Primer proyecto (`t2-html-css/t2-html`)**: se han retirado las fotos y los vídeos originales, así que esas imágenes no se verán.
- No se incluyen los enunciados ni el material del profesorado.
